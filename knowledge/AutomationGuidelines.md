# Automation Guidelines

Always automate:

- Safety alarms
- BACnet communication
- Modbus communication
- Controller logic
- A2L Leak Detection
- Furnace control
- Compressor restart
- Controller Restart
- Compressor Restart

Boundary values must be tested.

Negative scenarios must exist.

Recovery scenarios must exist.

Communication failures should verify retries.

Performance tests should include response times.

Stress tests should execute repeated cycles.

Avoid duplicate test cases

Always include

Positive tests

Negative tests

Boundary tests

Recovery tests

Performance tests

Stress tests

Safety tests
